# Plain text wins

I have written in at least nine tools since 2010. Two of them no longer exist, three changed their file format, and one locked my notes behind a subscription I stopped paying for.

The plain text files from that whole period open instantly, in anything, on any machine.

## The argument in one line

A format you can read with `cat` will outlive every company that promises to keep your notes safe.

## Markdown is enough

Headings, emphasis, lists, links, and the occasional code block cover almost everything prose needs:

```markdown
# a heading

some *emphasis*, a [link](https://example.com), and

- a list
```

Everything beyond that is layout, and layout belongs to whoever renders the file, not to the file.

---

## What you give up

Real-time collaboration is worse. Images are clumsier. There is no comment thread in the margin.

Those are real losses. They are also *temporary* losses, because the tools keep improving. The loss of a decade of notes to a dead format is not temporary.
