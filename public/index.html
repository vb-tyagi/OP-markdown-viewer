    saving

    direct folder saving optional

    what it is. instead of saving copies, the page writes your edits straight back into the original files. you pick a folder, and the browser asks once for permission to read and write inside that folder and nowhere else.

    how it works. it uses the browser's File System Access API (Chrome, Edge, Brave, Arc, Opera). every save writes through a temporary file, reads the result back, and compares it byte for byte. the previous version is copied first into .op-markdown-viewer-backups/ inside your folder (the newest 30 per file are kept). if a file changed on disk since you opened it, you are asked before it is overwritten.

    what it never does. it does not touch files outside that folder, does not create files other than backups, and does not upload anything. the permission belongs to this site and that folder only; the browser shows it in the address bar, where you can revoke it. closing the tab ends the access.

    without it. you open files, edit, and press “save a copy”. a save dialog lets you choose where each copy goes, and your originals stay untouched unless you deliberately pick them.

    AI reviewer optional

    what it is. a second opinion on formatting only. it reads the original and the edited text and reports broken headings, lost quotes or markers, merged paragraphs, and leftover editing artifacts. it never comments on your writing.

    what it needs. either your own Anthropic API key, used from this page directly to api.anthropic.com and nowhere else (kept in the tab's session storage unless you choose to remember it), or the local companion (npm start), which runs your own claude CLI on your machine.

    what it sends, and when. the file name, the original text, the edited text, and your style notes. only when you press “AI review”, or on every save if you switch that on. with your key, a review typically costs a few cents.

    without it. the built-in formatting guard still runs on every save, entirely inside your browser, with no network at all.
