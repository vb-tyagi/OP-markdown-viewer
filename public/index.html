    OP-markdown-viewer

    edit markdown files on your own computer, in your browser. every save writes straight to the file, through a formatting guard that catches accidental damage. nothing is uploaded.

    this browser cannot write files directly. you can still open files, edit them, and download the edited copies. for saving in place use Chrome, Edge, Brave, or Arc.

    • saves are atomic, verified byte for byte, and preceded by a backup copy inside your folder ().
    • a deterministic formatting guard runs on every save. an optional AI reviewer can double-check, using your own Anthropic API key or a local claude CLI.
    • no accounts, no analytics, no cookies. the only network request the page can make is to api.anthropic.com, and only if you turn the AI reviewer on. source on GitHub.
